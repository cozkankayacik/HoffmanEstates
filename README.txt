WORKING RULES
Keep existing source filenames. The supplied DWG is stored under Shared CAD;
do not assume it belongs to a single alternative. Check Xrefs when opening it.
Start new option-specific editable files inside that option's CAD folder.
Keep all files for an additional option together using the same CAD/PDF pattern.
For new files use: HE_Alt-01_First-Floor_2026-09-29_R01.pdf
Use YYYY-MM-DD dates and explicit revisions; avoid names such as final_final.
For an issue, create a dated folder under Issued_Sets and copy the issued files
there. Archive superseded working revisions rather than overwriting issued sets.
Source_Inventory.csv records original names, current locations, sizes and SHA256
checksums, allowing the five supplied files to be checked after reorganization.
